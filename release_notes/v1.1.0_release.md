# CipherFS v1.1.0 - Security Hardening & Power User Update

## New Features
*   **Automatic Updates**: Added `update` command to fetch the latest binary directly from GitHub.
*   **Enhanced Security**:
    *   **Nonce Randomization**: Implemented unique random nonces for DEK and Index to prevent cryptographic reuse attacks.
    *   **Input Validation**: Added checks for Argon2 parameters and Index sizes to prevent DoS/OOM attacks.
    *   **Path Traversal Protection**: Sanitized file extraction paths to prevent overwriting system files.
*   **Stack Safety**: Rewrote directory traversal logic from recursive to iterative, supporting extremely deep directory structures.

## Improvements
*   **Power User Flexibility**: Relaxed security limits to support Argon2 memory up to 32GB and indexes up to 4GB.
*   **Code Cleanup**: Removed unused dependencies and refactored signal handling for cleaner code.
*   **Documentation**: Fully translated README and release notes to English.

## Bug Fixes
*   Fixed critical type mismatch errors in FUSE error reporting.
*   Fixed a bug where `extract` would fail if the destination directory already existed.
