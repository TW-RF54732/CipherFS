# CipherFS v1.5.0 - Static Musl Build & Zero Dependency Release

## New Features
*   **Fully Static Binary**: Switched the primary build target to `x86_64-unknown-linux-musl`. The resulting binary is now fully statically linked and contains all necessary libraries, including the C standard library.
*   **Zero System Dependencies**: Removed dependencies on system-level libraries such as `GLIBC`, `libfuse3`, and `OpenSSL`. This ensures `cipherfs` can run on any Linux distribution regardless of the installed library versions.

## Improvements
*   **Pure-Rust FUSE Implementation**: Migrated to `fuser`'s native Rust mounting logic, eliminating the need for the `libfuse` C library.
*   **Rustls Integration**: Switched the update mechanism to use `rustls` instead of `native-tls`, removing the requirement for system OpenSSL.
*   **Enhanced Compatibility**: The binary is now compatible with older Linux kernels and distributions (e.g., CentOS 7, older Ubuntu/Debian releases) that lack modern GLIBC versions.

## Maintenance
*   Updated CI/CD pipeline to automate the musl build and testing process.
*   Maintained all interactive update and security features from previous versions.
