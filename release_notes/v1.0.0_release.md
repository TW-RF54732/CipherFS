# CipherFS v1.0.0 - Initial Stable Release

## New Features
*   **High-Performance Mounting**: Utilizes Linux-native concurrent read technology to fully leverage multi-core performance.
*   **Automatic Updates**: New `update` command to upgrade directly from GitHub.
*   **Graceful Unmount**: Integrated Linux signal handling for safe unmounting via Ctrl+C.
*   **Duress Protection**: Support for a secondary password to neutralize the vault (Data Encryption Key destruction) in emergency situations.
*   **CI/CD Integration**: Automated build and E2E testing for every release.

## Improvements
*   Fixed chunk offset calculation bugs during multi-file packing.
*   Removed unnecessary global locks, significantly improving mount read speeds.
*   Refactored codebase for pure Linux environments.
