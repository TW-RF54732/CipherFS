# CipherFS v1.2.0 - Expert Mode (Relative Rooting) & Dynamic Resource Update

## New Features
*   **Expert Mode (Relative Rooting)**: All path validation has been refactored. CipherFS now allows `..` and absolute-style paths in the index, but **grounds them in the user-specified output directory**.
    *   Example: Extracting to `~/vault` with an index entry `/etc/passwd` will now write to `~/vault/etc/passwd`, preventing accidental system file overwrites while maintaining full structural flexibility.
    *   Relative jumps using `..` are allowed and start from the specified destination.
*   **Dynamic Resource Limits**: Resource constraints are no longer hardcoded. Limits are specified during `pack` and stored in the header:
    *   **Argon2 Parameters**: Custom `m_cost`, `t_cost`, and `p_cost` via CLI flags.
    *   **Index Size Limit**: Custom maximum index size per container.
*   **CLI Enhancements**: New flags for the `pack` command:
    *   `--m-cost`, `--t-cost`, `--p-cost`, `--max-index`.

## Security Note
*   **Expert Tool**: Users are responsible for the directory structure within their containers. While absolute paths are "rooted" to the destination, excessive `..` components can still reach outside the destination if not used carefully.

## Improvements
*   Enhanced `extract` logic to automatically create missing parent directories during complex path reconstruction.
