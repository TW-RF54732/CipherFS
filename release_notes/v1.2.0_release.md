# CipherFS v1.2.0 - Expert Mode & Dynamic Resource Update

## New Features
*   **Expert Mode (Removed Path Restrictions)**: All path validation during extraction has been removed. CipherFS now allows absolute paths, relative paths, and `..` traversal in the archive index, giving full control to the user.
*   **Dynamic Resource Limits**: Resource constraints are no longer hardcoded. Users can now specify limits during the `pack` process, which are stored in the container header:
    *   **Argon2 Parameters**: Custom `m_cost`, `t_cost`, and `p_cost` can be set via CLI flags.
    *   **Index Size Limit**: Custom maximum index size can be set per container.
*   **CLI Enhancements**: Added new flags to the `pack` command:
    *   `--m-cost`: Set Argon2 memory cost.
    *   `--t-cost`: Set Argon2 time cost.
    *   `--p-cost`: Set Argon2 parallelism.
    *   `--max-index`: Set maximum allowed index size (in MB).

## Security Note
*   **User Responsibility**: By removing path traversal protection, CipherFS is now an "Expert Tool." Users are responsible for ensuring that the archives they extract or mount do not contain malicious paths if used in sensitive environments.

## Improvements
*   Updated Header format to persist resource limits.
*   Synchronized `extract` and `mount` to respect container-specific resource bounds.
