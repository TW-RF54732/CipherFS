# CipherFS v2.2.0-rc.1 - cross-platform release candidate

This candidate exercises the complete v2.2.0 Linux FUSE, Windows WinFsp,
transactional extraction, dependency-policy and signed-artifact release gates.
It is a prerelease for clean-machine validation and is not promoted to
`releases/latest`.

See `v2.2.0_release.md` for the intended final behavior, requirements,
compatibility and limitations. Any code or packaging fix after this candidate
requires another release candidate and a complete rerun of both runtime gates.
