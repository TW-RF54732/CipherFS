# CipherFS v1.3.0 - Interactive Update & Improved CLI Experience

## New Features
*   **Interactive Update**: The `update` command now provides a better user experience by:
    *   Fetching the latest release notes from GitHub before updating.
    *   Displaying the new version number and its corresponding changes.
    *   Asking for explicit user confirmation (`[y/N]`) before proceeding with the binary replacement.
*   **Version Check**: Improved logic to prevent unnecessary downloads if the current binary is already up to date.

## Improvements
*   Enhanced error reporting during the update configuration and execution phases.
*   More informative status messages during update checks.

## Security & Maintenance
*   Continued usage of random nonces and iterative tree traversal for robust performance and security.
*   Expert mode (relative rooting) and dynamic resource limits from v1.2.0 are fully maintained.
