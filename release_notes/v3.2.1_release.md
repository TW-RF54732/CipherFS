# CipherFS v3.2.1 - Balanced Desktop Parallelism

## Downloads

- `CipherFS-Setup-x64.exe` - recommended Windows installer. It installs
  CipherFS and installs the pinned WinFsp runtime only when needed.
- `cipherfs-windows-portable-x64.zip` - advanced Windows portable package. It
  does not modify PATH, the Registry, Explorer integration, or Installed apps.
- `cipherfs-linux-x64.tar.gz` - Linux archive.
- `cipherfs` - directly downloadable Linux portable ELF.

The Windows builds are not Authenticode-signed, so Windows may display
**Unknown publisher**. Minisign signatures, SHA-256 files, GitHub Artifact
Attestations, raw binaries, source, licenses, and compatibility manifests are
provided as advanced verification material.

## Changes

- Pack, extract, and verify now default to half of the available logical CPU
  parallelism, rounded down and capped at six workers, with a minimum of one.
  This reduces unnecessary CPU and I/O contention during normal desktop use.
- The Windows Shell uses the shared CipherFS Core default and no longer selects
  an operation worker count itself.
- CLI users can still pass `--threads 0` to use all available logical CPU
  parallelism, or a positive value to select an exact worker count.

## Compatibility and requirements

- The v2 container format and existing v3 CLI data operations remain
  compatible with CipherFS v3.2.0.
- Windows mounting requires WinFsp. Setup installs the pinned compatible
  runtime when it is missing and does not automatically downgrade a newer
  installation.
- Linux mounting requires FUSE 3.
- CipherFS remains an experimental personal/offline privacy tool. It has not
  received a professional security audit and must not be the only copy of
  valuable data.

## Updating

- Installed Windows copies: run the newer `CipherFS-Setup-x64.exe`; Setup owns
  upgrade, repair, and uninstall behavior.
- Windows portable copies: download and extract the newer portable ZIP.
- Linux: use the signed `cipherfs update` command or replace the portable ELF.
