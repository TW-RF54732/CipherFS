# CipherFS v2.2.0-beta.1 - Windows WinFsp Preview

This prerelease introduces a Windows x86-64 build and separates the encrypted
read-only filesystem core from the Linux FUSE and Windows WinFsp adapters.

## Changes

- Adds read-only WinFsp mounting for v1 and v2 containers at a drive letter,
  empty directory, or automatically selected drive.
- Makes pack, extract, verify, passwd, and signed update code build on Windows.
- Extracts the legacy v1 reader from FUSE-specific callbacks.
- Maps Windows-reserved, invalid, overlong, and case-colliding names to stable
  display names without changing the authenticated container index.
- Preserves all-or-error reads for corrupted chunks and delayed extraction
  commits.

## Requirements and limitations

Install the official WinFsp 2.1 runtime separately. CipherFS does not bundle an
installer or Authenticode signature, so Windows may show a SmartScreen warning.
This remains experimental software for casual/offline privacy of non-critical
files. Keep independent backups.
