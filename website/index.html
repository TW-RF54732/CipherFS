開放原始碼 · Local-first · 實驗性軟體

Windows Shell workflow

不離開檔案總管
也能封裝私人檔案

從選取資料夾到開啟加密容器，日常操作都留在熟悉的 Windows 介面。

01 / EXPLORER

從右鍵選單開始

選取資料夾，使用 Pack with CipherFS，不用先切換到終端機。

02 / PACK

建立單一 .cfs 容器

選擇輸出位置並設定密碼。資料夾內容會被封裝成一個便於移動與保存的容器檔案。

03 / OPEN

一個 .cfs
四種清楚的操作

開啟容器後，可以掛載、解開、驗證完整性，或變更密碼。

  • Mount
  • Extract
  • Verify
  • Change password

Read-only mount

像磁碟一樣瀏覽
不必先完整解開

CipherFS 透過 WinFsp 將容器掛載成唯讀磁碟，讓你直接在 Explorer 中瀏覽內容。

RESULT / EXPLORER

容器內容會出現在獨立磁碟機代號中；關閉掛載視窗即可結束存取。

Designed with boundaries

功能明確
界線也明確

01

Local-first

封裝、掛載與驗證都在本機完成，不依賴雲端服務。

02

單一容器

檔案與資料夾被整理成一個 .cfs 檔案，便於移動與保存。

03

唯讀瀏覽

透過 WinFsp 掛載時保持唯讀，避免瀏覽過程改動容器內容。

04

Open source

程式碼、格式與測試方式公開，可在 GitHub 上檢視。

Experimental feature

可選的 Duress Password

建立容器時可以設定實驗性的脅迫密碼。這項功能仍在測試階段，不應被視為已驗證的反鑑識或安全保證。
