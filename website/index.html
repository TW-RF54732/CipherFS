CipherFS / Windows x64

加密保存，
像磁碟一樣瀏覽。

把資料夾封裝成加密的 .cfs 容器。需要使用時，直接掛載成唯讀磁碟，不必先完整解開。

從資料夾開始

熟悉的操作，多一層加密。

封裝、開啟與瀏覽，都從 Windows 檔案總管接續進行。

01 / 建立容器

從右鍵開始，
收進一個檔案。

選取資料夾，使用 Pack with CipherFS，選擇輸出位置並設定密碼，即可建立單一 .cfs 容器。

Windows 11 的指令位於「顯示其他選項」。

02 / 開啟容器

一個容器，
四種清楚的操作。

雙擊 .cfs 檔案，選擇這次需要的操作。

掛載
以唯讀磁碟瀏覽內容
解開
將檔案取出到新資料夾
驗證
核對整個容器的完整性
變更密碼
更換開啟容器的密碼
03 / 唯讀瀏覽

打開檔案總管，
直接找到需要的檔案。

透過 WinFsp，容器會出現在獨立的磁碟機代號中。瀏覽時保持唯讀，不會改動容器內容。

掛載期間保持 Shell 視窗開啟，完成後按「Unmount」卸載。

關於實驗性 Duress Password

建立容器時可設定次要脅迫密碼；輸入後會覆寫容器標頭中的包裝金鑰。它不是經過驗證的安全清除或反鑑識保證，副本與備份仍可能保留資料。
