Installer 包含內容

  • 安裝 CipherFS CLI 與 Windows Shell
  • 整合 Explorer 右鍵選單與 .cfs 檔案關聯
  • 需要時安裝 WinFsp
  • 支援後續升級、修復與解除安裝

Before installation

安裝前需知

01 / ADMIN

需要管理員權限

Setup 會執行 machine-wide 安裝，整合 Explorer，並在需要時安裝 WinFsp。

02 / SIGNING

可能出現 Unknown publisher

目前 Windows build 沒有 Authenticode code-signing certificate。

03 / PRIVACY

檔案留在本機

CipherFS 的封裝、掛載與驗證流程不需要把檔案上傳到雲端。

After installation

安裝完成
從右鍵開始

  1. 在 Explorer 選取資料夾。
  2. Windows 11 使用者如有需要，先展開「顯示其他選項」。
  3. 選擇 Pack with CipherFS，建立 .cfs 容器。
