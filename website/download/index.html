Installer 會做什麼？

  • 安裝 CipherFS CLI 與 Windows Shell
  • 加入 Explorer 右鍵指令與 `.cfs` 關聯
  • 缺少相容 WinFsp 時安裝固定版本
  • 支援日後升級、修復與解除安裝

Setup 是離線安裝程式。移除 CipherFS 時會保留可能由其他程式共用的 WinFsp。

Before installation

安裝前，先知道這三件事。

01 / ADMIN

需要系統管理員核准

Setup 會進行 machine-wide 安裝、建立 Explorer 整合，並在需要時安裝 WinFsp。

02 / SIGNING

Windows 可能顯示警告

目前 Windows build 沒有 Authenticode code-signing certificate，因此可能顯示 Unknown publisher。

03 / PRIVACY

檔案留在你的電腦

網站只提供安裝檔連結；CipherFS 的封裝、驗證與解開流程在本機進行。

After installation

安裝完成，從右鍵開始。

不需要先設定帳號或連接雲端。安裝後直接回到檔案總管：

  1. 在檔案或資料夾上按右鍵。
  2. Windows 11 使用者若未看到指令，選擇「顯示其他選項」。
  3. 選擇 Pack with CipherFS 建立容器，或雙擊既有的 .cfs。
